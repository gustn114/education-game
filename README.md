# education-game

수업에서 쓰는 교육용 웹 게임 모음입니다. 게임마다 폴더 하나에 `index.html` 파일 하나로 들어 있어서, 파일을 브라우저로 열면 바로 실행됩니다.

## 게임 목록

| 게임 | 폴더 | 설명 |
| --- | --- | --- |
| 선생님 몰래 간식 먹기 | [`sneaky-snack`](sneaky-snack/index.html) | 바이브코딩 창의게임 만들기 수업의 시연 게임. 2인 대전으로, 선생님이 판서하는 동안 키를 눌러 몰래 간식을 먹고 돌아볼 때 손을 떼는 게임 |

## 선생님 몰래 간식 먹기

- 조작: 1P는 A키, 2P는 L키를 누르고 있으면 간식을 먹습니다. Space로 시작, M으로 소리 끄기.
- 규칙: 1초에 3점씩 오르고, 선생님이 돌아봤을 때 먹고 있으면 5점이 깎이며 3초 동안 복도에 서 있습니다. 40초 뒤 점수가 높은 사람이 이깁니다.
- 반전: 25초가 남으면 선생님이 돌아보는 척만 하기도 하고, 10초가 남으면 교감선생님이 창문에 나타납니다.
- 설정 바꾸기: `index.html`의 `<script>` 맨 위 `CONFIG`에서 게임 시간, 점수, 신호 시간, 간식 이모지 등을 바꿀 수 있습니다.
